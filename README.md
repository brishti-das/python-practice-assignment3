# Employee Salary Management System

This repository contains a simple Employee Salary Management System developed using Python.

## Features

### Feature 1: Add Employee
- Takes employee name, ID and salary as input.
- Saves employee information into a text file (`employees.txt`).
- Uses Append Mode to store employee records.

### Feature 2: View Employees
- Reads all employee records from the text file.
- Displays employee information.
- Uses Read Mode to retrieve stored data.

## Technologies Used
- Python
- File Handling
